# Sobolev Training for Option Pricing Surrogates

Welcome to the documentation of the **Sobolev Training for Option Pricing Surrogates** project.

This project was developed as part of a university software engineering project at **RWTH Aachen University**. The objective is to investigate the use of **Higher-Order Sobolev Training** for neural network surrogate models in quantitative finance.

This documentation provides an overview of the project motivation, theoretical background, implementation, and repository structure. It is intended for both developers and readers who would like to understand the project and its architecture.

## Project Objectives

The project aims to

- develop a neural network surrogate model for option pricing,
- improve approximation quality using Higher-Order Sobolev Training,
- compare the surrogate with the original mathematical pricing model,
- demonstrate the surrogate in practical applications such as calibration and risk analysis.
